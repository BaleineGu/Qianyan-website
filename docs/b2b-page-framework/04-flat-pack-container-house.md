### Banner
- **H1:** Heavy-Duty Flat Pack Container Houses for Project Sites
- **Description:** Cost-effective, robust, and scalable modular systems for temporary offices, worker camps, and remote site headquarters.

### Key B2B Procurement Advantages
- **Freight optimization:** Multiple flat-packed units can share one ISO container footprint, reducing ocean logistics cost.
- **Modular scalability:** Stack up to 3 floors and link horizontally for larger compounds.
- **Rapid assembly:** Corner columns bolt into roof and floor assemblies; a standard unit structure can lock in under 30 minutes with a four-person crew.

### Material Specifications
- **Main frame:** 3.0–4.0mm hot-dip galvanized and powder-coated steel with drainage pathways in corner columns
- **Insulation core:** 50mm / 75mm high-density fire-retardant Rockwool sandwich panels
- **Windows / doors:** Double-glazed aluminum sliding windows with security shutters; steel security external doors
