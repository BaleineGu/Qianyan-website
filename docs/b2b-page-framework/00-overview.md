## Brand Voice

| Do | Don't |
|----|-------|
| Professional, practical, reliable, solution-oriented, clear, export-ready | Unverified claims, pressure selling, cheap-only pitch, vague hype |
| Direct B2B English, simple sentences, concrete specs | Over-technical text without buyer context |

**Conversion priority:** Inquiry → WhatsApp → Contact form → Catalog download  
**Market priority:** US/Canada → Australia/NZ → Middle East → Southeast Asia → Europe  
**Product priority:** Expandable → Space Capsule → Flat Pack → Folding → Container Pool
